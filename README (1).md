# รู้จักกันแค่ไหน — เกมคู่รัก (เล่นบนเครื่องเดียว)

เกมทายใจคู่รัก ผลัดกันตอบบนจอเดียวกัน — ไม่ต้องมีอินเทอร์เน็ต ไม่ต้องมีเซิร์ฟเวอร์ เปิดไฟล์แล้วเล่นได้เลย

## โครงสร้างไฟล์

```
couple-quiz/
├── index.html   ← โครงหน้าเว็บ
├── style.css     ← ดีไซน์ + แอนิเมชันทั้งหมด
└── script.js     ← ลอจิกเกมทั้งหมด
```

ไฟล์ทั้ง 3 ต้องอยู่**โฟลเดอร์เดียวกัน** ห้ามแยกคนละที่ เพราะ `index.html` อ้างอิงถึงอีกสองไฟล์ด้วยชื่อไฟล์ตรงๆ

## วิธีเปิดเล่น

เลือกวิธีใดวิธีหนึ่ง:

- **ง่ายที่สุด:** ดับเบิลคลิกที่ `index.html` เพื่อเปิดในเบราว์เซอร์โดยตรง
- **ใน VSCode:** ติดตั้งส่วนขยาย **Live Server** → คลิกขวาที่ `index.html` → เลือก "Open with Live Server"

ไม่ต้องรัน `npm install` หรือคำสั่งใดๆ เพิ่มเติม

## วิธีเล่น

1. ใส่ชื่อทั้งสองคน
2. แตะซองจดหมายในหน้าอินโทรเพื่อเริ่ม
3. แต่ละข้อจะสลับกันว่าใครเป็น **"เจ้าของคำตอบ"** — คนนั้นเลือกคำตอบจริงของตัวเองก่อน (ห้ามอีกฝ่ายเห็นจอ)
4. ส่งจอให้อีกฝ่าย **"ทาย"** ว่าคำตอบของคนแรกคืออะไร
5. เฉลยทันทีว่าทายถูกหรือผิด พร้อมเอฟเฟกต์และเสียงประกอบ
6. ครบ 12 ข้อ จะเห็นคะแนนแยกของแต่ละคน มิเตอร์หัวใจแสดงเปอร์เซ็นต์ความเข้าใจกัน และคำคมหวานๆ

## ฟีเจอร์ที่มี

- หน้าอินโทรซองจดหมายเปิดได้ (แตะหรือกด Enter/Space)
- เสียงเอฟเฟกต์สังเคราะห์ในตัว (คลิก, เลือกคำตอบ, ส่งจอ, ทายถูก/ผิด, สตรีคทายถูกติดกัน, แฟนแฟร์ตอนจบ) — ปิด/เปิดได้ด้วยปุ่ม 🔊 มุมขวาบน
- หัวใจลอยพื้นหลังเบาๆ ตลอดเกม และหัวใจกระจายตอนทายถูก/จบเกม
- นับสถิติทายถูกติดกัน (สตรีค) พร้อมเก็บสถิติสูงสุด
- มิเตอร์รูปหัวใจเติมสีตามเปอร์เซ็นต์ความเข้าใจกันเฉลี่ย
- คำคมหวานๆ 12 แบบ (4 ระดับคะแนน ระดับละ 3 แบบ) กดสุ่มคำคมใหม่ได้
- ปุ่มคัดลอกผลลัพธ์ไปแชร์ต่อ
- รองรับผู้ใช้ที่ตั้งค่า "ลดการเคลื่อนไหว" ในเครื่อง (ปิดแอนิเมชันอัตโนมัติ)

## ปรับแต่งคำถาม / คำคม

เปิดไฟล์ `script.js` แล้วแก้ไขได้ที่:

- ตัวแปร `QUESTIONS` — เพิ่ม/ลบ/แก้คำถามและตัวเลือก (แต่ละข้อมี 4 ตัวเลือกเป็นมาตรฐาน แต่ใส่มากกว่านี้ก็ได้)
- ตัวแปร `QUOTES` — แก้คำคมในแต่ละระดับ (`top`, `high`, `mid`, `low`)

## ปรับแต่งสีธีม

เปิดไฟล์ `style.css` แล้วแก้ค่าตัวแปรสีในบล็อก `:root` ด้านบนสุด เช่น `--rose`, `--gold`, `--bg` เพื่อเปลี่ยนธีมสีทั้งหมดในทีเดียว
